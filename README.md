# Свойства материала и режим давления при сверхпластической формовке

Программная реализация к работе «Определение свойств сверхпластичного материала с помощью свёрточных нейронных сетей и итерационный выбор режима давления при сверхпластической формовке».

Репозиторий содержит две независимые части:

1. **`material_identification/`** — восстановление параметров *K* и *m* закона Бэкофена σ = K·ε̇^m по кривым «напряжение–деформация» стандартного испытания на растяжение (ASTM E2448) с помощью моделей машинного обучения, обученных на синтетической выборке из конечно-элементных расчётов испытания.
2. **`pressure_algorithm/`** и **`abaqus_subroutines/`** — итерационный алгоритм выбора режима давления при сверхпластической формовке по уровням заполнения матрицы, пользовательские подпрограммы Abaqus для определяющих соотношений и регулятор давления по скорости деформации.

## Структура

```
abaqus_subroutines/

                                     в контрольной зоне (мультипликативный ПИД-закон, ограничение dp/dt)
  powerlaw_usdfld.for                USDFLD: закон Бэкофена (PLM = K^(-1/m), ESO = 1/m)
  poly_usdfld.for                    USDFLD: параметры, зависящие от накопленной деформации (полиномы)

pressure_algorithm/
  fill_pressure_optimizer_nogui.py   алгоритм выбора давления (основная версия, пакетный режим Abaqus/CAE)
  fill_pressure_optimizer_gui.py     вариант для открытой сессии Abaqus/CAE
  postprocessing/                    толщина по профилям (compute_distances.py), заполнение матрицы
                                     (find_area_ratio.py), разбор отчётов Abaqus (.rpt)

                масштабирование кривых по K (generate_txt_with_new_K.py), сборка CSV (create_general_csv.py)
  models/       обучение моделей: регрессионное дерево, градиентный бустинг, полносвязная сеть,
                свёрточная сеть (PyTorch); group_split.py — групповое разбиение по m

```

## Требования

* Части с Abaqus: Abaqus/Standard и Abaqus/CAE (Python 2.7 в составе Abaqus), компилятор Fortran, совместимый с вашей версией Abaqus (для пользовательских подпрограмм).
* Части на Python 3: см. `requirements.txt` (numpy, pandas, scipy, scikit-learn, matplotlib, joblib, torch, optuna).

```bash
pip install -r requirements.txt
```

Все скрипты запускаются из корня репозитория. Пути к данным задаются в блоке настроек в начале каждого скрипта и по умолчанию указывают в каталог `data/` (см. `data/README.md`).

## 1. Восстановление параметров материала

### Идея

Набор из *M* кривых «напряжение–деформация» (при *M* постоянных скоростях деформации), заданных в *N* общих точках по деформации, отображается в пару (*K*, *m*). Обучающая выборка получается конечно-элементным моделированием самого испытания, поэтому влияние геометрии образца и неоднородности деформации учтено в данных.

Свойство подобия: при кинематических граничных условиях и законе Бэкофена кривая для параметров (*K*, ε̇) получается из опорной кривой (*K*₀, ε̇₀) умножением напряжений на (K/K₀)·(ε̇/ε̇₀)^m. Поэтому достаточно одного конечно-элементного расчёта на каждое значение *m*; кривые для остальных *K* и скоростей деформации генерируются скриптом `dataset/generate_txt_with_new_K.py`.

### Формат выборки

CSV (разделитель `;`), одна строка — один объект:

| столбцы | смысл |
|---|---|
| `K`, `m` | целевые переменные |
| `e_1 … e_N` | общие точки по деформации |
| `s_i_er<rate>` | напряжение в точке `e_i` для скорости деформации `<rate>` (например, `s_3_er0p0004`) |
| `er_<rate>` | значение скорости деформации |

### Обучение

```bash
cd material_identification/models
python launch_learning.py            # последовательно: дерево, бустинг, полносвязная сеть, свёрточная сеть
```

Путь к выборке — переменная `CSV_PATH` в начале каждого скрипта.

**Разбиение выборки.** Объекты с одинаковым *m* получены масштабированием одной опорной кривой и отличаются постоянным множителем, поэтому они целиком относятся либо к обучающей, либо к тестовой части (20 % объектов); подбор гиперпараметров выполняется пятикратной групповой кросс-валидацией по тем же группам (`group_split.py`). Случайное разбиение по объектам даёт завышенную оценку точности.

Сетки гиперпараметров: дерево — 324 конфигурации, бустинг — 72 конфигурации отдельно для *K* и *m*, полносвязная сеть — случайный поиск 30 конфигураций (Optuna). Свёрточная сеть: два слоя 3×3 (каналы задаются `CONV_CHANNELS`), адаптивный средний пулинг 4×4, конкатенация с векторами деформаций и ln ε̇, полносвязные слои 64 и 2; Adam, до 200 эпох с ранней остановкой (`PATIENCE`).

## 2. Алгоритм выбора режима давления

### Идея

Процесс делится на этапы по заполнению матрицы

H = (S − S₀) / (S_d − S₀),

где *S* — площадь под профилем верхней поверхности заготовки в меридиональном сечении, *S*₀ — то же в исходном состоянии, *S_d* — площадь под профилем матрицы. На этапе *k* для каждого давления из сетки *P* выполняется расчёт-кандидат из состояния, выбранного на этапе *k* − 1 (restart Abaqus). Кандидаты, не достигшие заполнения *H_k* = *k*·Δ*H* за время `STAGE_TIME`, отбрасываются; из остальных выбирается давление с наибольшей минимальной толщиной заготовки при *H* = *H_k*. Результат — кусочно-постоянный режим *p*(*t*), который затем можно сгладить.

### Запуск

```bash
abaqus cae noGUI=pressure_algorithm/fill_pressure_optimizer_nogui.py
```

Основные параметры (в начале скрипта):

| параметр | значение в работе | смысл |
|---|---|---|
| `CAE_FILE`, `WORK_DIR` | — | модель Abaqus/CAE и рабочий каталог расчётов |
| `PRESSURE_VALUES` | 0,1; 0,3; …; 1,5 МПа | сетка давлений *P* |
| `FILL_STEP` | 0,1 | шаг по заполнению Δ*H* |
| `FINAL_FILL_TARGET` | 0,8 | целевое заполнение *H** |
| `STAGE_TIME` | 400 с | максимальная длительность этапа *T*_max |
| `RAMP_TIME` | 0,5 с | время перехода к новому давлению |
| `DIE_AREA` | 15995,9 мм² | площадь под профилем матрицы *S_d* |
| `NODES_THROUGH_THICKNESS` | 7 | число узлов по толщине (для выделения верхнего и нижнего слоёв) |
| `USER_SUBROUTINE` | `abaqus_subroutines/smirnov_usdfld.for` | подпрограмма материала |

Скрипт пишет в `LOG_DIR` журнал всех кандидатов (`*_summary.csv`), выбранный путь (`*_best_path.csv`), режим для воспроизведения (`*_pressure_schedule.csv`) и итог (`*_final_result.txt`).

### Пример: прогон из работы

`pressure_algorithm/example_run/run_19/` — журналы прогона для заготовки радиусом 200 мм и толщиной 4 мм из сплава Ti-6Al-4V (уравнение Смирнова, 800 °C): 8 этапов × 8 давлений, выбранная последовательность 0,3; 0,5; 0,9; 1,1; 1,3; 1,5; 1,5; 1,5 МПа, заполнение 0,8 достигнуто за 1006 с при минимальной толщине 2,598 мм.

Рисунки сравнения режимов строит `pressure_algorithm/plots/nirs_figures.py`.
