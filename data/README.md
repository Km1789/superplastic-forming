# Данные (не входят в репозиторий)

Скрипты по умолчанию ожидают такую структуру:

```
data/
  forming/
    model/free_bulg.cae, alg_try.inp        модель формовки Abaqus
    logs/run_01/                            сюда пишет журналы алгоритм выбора давления
    Free_bulg_test/Reports/Smirnov_parsed/Frictionless/<режим>/increment_<N>/top.txt, bottom.txt
                                            профили верхней и нижней поверхности заготовки
                                            (первая строка: "Time: <t>", далее пары x y)
    sr_opt_tp.csv                           история давления режима поддержания ε̇_opt (t, p)
  material/
    Txt_files/...                           кривые «напряжение–деформация» из расчётов испытания
    Datasets/*.csv                          собранные выборки (формат описан в корневом README)
    Graphics/...                            сюда пишутся результаты обучения
```

Пути можно изменить в блоке настроек в начале каждого скрипта.
